# Last Asylum Bot

Бот для BlueStacks (ADB + OpenCV). Три режима фарма, управление энергией.

## Установка

```
python -m venv .venv && .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Требует включённый ADB в BlueStacks (Настройки → Дополнительно → ADB) и
разрешение экрана **1080×1920** — все координаты привязаны к нему.

## Запуск

```
python -m src.app        # GUI: Start / Stop + поле «Мин. остаток склянок»
```

## Режимы (`config.py`, поле `strategy`)

| Значение | Режим |
|---|---|
| `corruption` | **Элитная скверна** — штурм боссов через диалог поиска (по умолчанию) |
| `thief` | «Поиск вора» — фарм мобов у базы (нужен `use_search_strategy=True`) |
| `map` | Детекция целей на отзумленной карте мира |

### Режим «Элитная скверна»

Цикл: лупа → вкладка «Элитная скверна» → «Поиск» (панель босса открывается
сама) → «Штурм» → «Начать Штурм». Отправляет, пока в виджете «Отряд N/4»
есть свободные слоты.

Что бот **не** трогает — это выставляет человек: уровень скверны, «Время
штурма», зум. Награды не собирает.

Останавливается, когда энергии не хватает на штурм, при трёх провалах подряд
и по кнопке Stop / файлу `STOP`.

Спека и план: `docs/2026-08-04-corruption-mode-design.md`,
`docs/2026-08-04-corruption-mode-plan.md`.

## Инструменты

```
python -m tools.corruption_run 2 12   # живой прогон скверны: 2 отправки, до 12 итераций
python -m tools.probe_squads          # что бот видит в виджете «Отряд N/4»
python -m tools.search_run 3 60       # живой прогон «Поиска вора»
python -m tools.dry_run               # решение движка без тапов
python -m tools.grab_screen shot.png  # снять кадр через ADB
```

## Тесты

```
.venv\Scripts\python.exe -m pytest -q
```

Тесты распознавания работают на реальных кадрах игры из `reference/` — там же
лежат негативные примеры (чужой диалог события, диалог выхода из игры,
потеря соединения).
