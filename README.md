# Last Asylum Bot
Бот для BlueStacks (ADB+OpenCV). Фарм мобов ур.5, штурм боссов, управление энергией.

## Установка
python -m venv .venv && .venv\Scripts\Activate.ps1
pip install -r requirements.txt

## Запуск
python -m src.app   # откроется GUI Start/Stop

Требует включённый ADB в BlueStacks (Настройки -> Дополнительно -> ADB).
