# CHANGELOG

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/), но
кратко — это журнал для одного человека, а не публичный релиз-нот.

## 0.2.0 — 2026-08-10

Новый режим: бот вступает в чужие сборы «Элитной скверны», а не только
запускает свои.

- Режим присоединения к чужим штурмам: красная иконка-череп на карте → окно
  «Война альянсов» → вкладка «Событие» → самый правый свободный зелёный «+»
  подходящей карточки → превью → «Отправиться».
- Переключатель режима в GUI: «Свой штурм» / «Присоединяться».
- Вступление бесплатное — энергия и склянки в этом режиме не тратятся.
- Отправка проверяется, а не объявляется: успех засчитывается только если
  вырос счётчик «Отряд N/4»; неподтверждённая отправка идёт в счётчик
  провалов, иначе бот молча крутился бы вхолостую на истёкшем сборе.
- Логика склянки +50 вынесена в общий `src/energy.py` (поведение своего
  штурма не изменилось).
- У `Vision` появились `find_all`, `join_cards`, `assault_call_icon`,
  `alliance_war_open`, `join_screen`, `refresh_button`.
- Живой раннер `tools/join_run.py` и инструмент `tools/mask_nicks.py`.
- Известное ограничение: бот не видит, что уже участвует в сборе. Пока в
  альянсе активен один сбор, после одного успешного вступления бот упирается
  в бюджет провалов и останавливается (подробности — в `CALIBRATION.md`,
  раздел «Прогон серией»).

## 0.1.0 — 2026-08-07

Состояние до появления CHANGELOG: свой штурм «Элитной скверны» (лупа →
«Элитная скверна» → «Поиск» → «Штурм» → «Начать Штурм»), поиск вора вместе с
фармом соседей-мобов, действия по карте (штурм босса, атака моба, explore),
сторож экрана (`src/watchdog.py`), GUI с кнопками Start/Stop, порогом
остатка склянок и чекбоксом 4-го отряда, распознавание цифр по шаблонам
(без Tesseract), калибровочные кадры в `reference/` и `CALIBRATION.md`.
